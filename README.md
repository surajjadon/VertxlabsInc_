# 📊 React Dashboard App

A responsive and dynamic user dashboard built with **React**, **React Router**, and **Tailwind CSS**, designed for mobile and desktop layouts. The app allows for user profile views, routing, charts, and social media integration.

---

## 🚀 Features

- ✅ Responsive mobile and desktop layout
- ✅ Dynamic user profile navigation
- ✅ React Router DOM-based routing
- ✅ Social media integration with `react-icons`
- ✅ Charts for analytics and visual data

---

## 🛠️ Tech Stack

- **React** (with hooks and JSX)
- **React Router DOM** for routing
- **Tailwind CSS** for styling
- **React Icons** for social and UI icons
- **Vite** (or Create React App if used)
- **React-chartjs-2** for charts

---

## 🐛 Vercel 404 Fix (Important)

If you're deploying this to **Vercel** and getting `404: NOT_FOUND` on page refreshes like `/user/2`, add the following `vercel.json` to your root:

```json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/" }
  ]
}
